- when writing php file, use the following example coding style, make sure that the php comments and html comments in example are presented
```php
<?php
//all application logic and data are here
?>
<!DOCTYPE html>
<html lang="en">
<!-- all html/javascript/css code are here -->
</html>
  ```
  the purpose of this is put the php logic and data on top and the page, as the presentation layer, are put in the bottom
