E2E Check Items for Gutenberg Book Reader (Puppeteer)
======================================================

1. Page loads without errors
2. URL bar with BurlyWood background exists
3. Book URL input field exists and is visible
4. Book content div exists with wheat background
5. Book content div has line-height 1.4
6. Entering a Gutenberg URL and pressing Enter loads book content
7. "Loading..." text appears while fetching
8. After loading, content is split into paragraphs (<p> elements)
9. Paragraphs contain pure text (no nested HTML tags other than button)
10. Each paragraph contains a "Convert to Simple English" button
11. Convert buttons have gold background
12. Convert buttons are inside the paragraph element (appended, not below)
13. Visible paragraphs show the convert button (IntersectionObserver)
14. Book URL is saved to localStorage "book_history"
15. Entries in "book_history" are unique
16. On reload, the last entry from book_history is loaded into the input
17. Modal appears when text is selected in book content
18. Modal is draggable
19. Modal has a close button that works
20. Modal body has vertical scrolling (overflow-y: auto)
21. Simple English modal has wheat background
22. LLM endpoint is called with correct model (gemma3:latest) and streaming
