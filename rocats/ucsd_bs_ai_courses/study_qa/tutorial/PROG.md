# Programming Fundamentals

This section covers the foundational programming skills taught in **CSE 8A/11** (Introduction to Programming) and **CSE 12** (Basic Data Structures and Object-Oriented Design). These courses form the bedrock of your computer science education at UCSD and are prerequisites for nearly every upper-division course in the BS AI program.

## What You Will Learn

Programming is the practice of writing precise instructions for a computer to execute. In these courses, you will move from writing your very first lines of code to designing modular, well-organized programs that solve real problems. The language used is **Java**, though the concepts transfer to any programming language you will encounter later.

## Module Breakdown

- **[Module 1 -- Variables & Control Flow](PROG-module-1.md)**
  Learn how programs store data in variables and make decisions using conditionals and loops. This is where every programmer starts.

- **[Module 2 -- Functions & Recursion](PROG-module-2.md)**
  Discover how to break large problems into smaller, reusable pieces with functions, and explore the elegant technique of recursion where a function calls itself.

- **[Module 3 -- OOP & Basic Data Structures](PROG-module-3.md)**
  Understand how object-oriented programming organizes code around objects and classes, and get your first look at data structures like arrays, linked lists, and stacks.

## Why It Matters for AI

Every AI system -- from a simple spam filter to a large language model -- is ultimately a program. Strong programming skills let you translate mathematical ideas into working software, debug unexpected behavior, and write code that others (and your future self) can read and maintain. Mastering these fundamentals early will make every subsequent course smoother and more enjoyable.

## Tips for Success

- Write code every day, even if only for 15 minutes.
- Read error messages carefully; they almost always point you to the problem.
- Use the UCSD CSE tutoring labs and Piazza forums whenever you get stuck.
